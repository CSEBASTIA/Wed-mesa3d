# Wed Escritorio 3D

Editor 3D en el navegador para diseñar escritorios a mano: agrega tableros, paneles laterales, estantes, faldones, patas y cajones, muévelos, cambia sus medidas y material, y obtén la lista de cortes.

## Cómo ejecutarlo

Necesitas [Node.js](https://nodejs.org).

```bash
node server.js
```

Luego abre http://localhost:5173

## Controles

- Arrastra una pieza para moverla; con Shift (o "Mover en altura") sube y baja.
- Arrastra el fondo para girar la vista; la rueda acerca y aleja.
- Doble clic en un cajón para abrirlo o cerrarlo.
- Flechas: mover · R: girar · Supr: eliminar · Ctrl+Z / Ctrl+Y: deshacer / rehacer.

Hecho con [three.js](https://threejs.org).
